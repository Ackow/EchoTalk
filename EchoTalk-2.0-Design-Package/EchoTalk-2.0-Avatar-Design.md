# EchoTalk 2.0：2D 交流伙伴

> 更新：2026-10-08。按用户要求仅保留 2D；3D 渲染器、选项、VRM 资源与依赖已移除。

## 形象

四个独立形象共用插画风格与互动坐标，但不共用发型、脸型和服装：

| ID | 形象 | 造型与性格 |
|---|---|---|
| `mira_2d` | Mira · 米拉 | 短发、耳麦、紫色针织衫；温柔耐心 |
| `vera_2d` | Vera · 薇拉 | 高马尾、利落下颌、金色耳环、白衬衫与绿色马甲；干练直率 |
| `nora_2d` | Nora · 诺拉 | 长直发、圆框眼镜、奶白高领与藏蓝翻领外套；沉稳专注 |
| `iris_2d` | Iris · 艾瑞丝 | 双丸子卷发、圆脸、大眼睛、雀斑、黄色连帽衫与斜挎带；活泼开朗 |

`CharacterPortrait.vue` 保留 Mira，并按形象 ID 分派其他造型到 `AlternatePortrait.vue`。
所有形象都是分层 SVG，舞台与缩略图共用组件；每个实例的渐变 ID 独立。
形象 ID 沿用现有值，已有选择继续生效；形象、声音与场景可自由搭配。
切换形象清除旧角色的微笑、台词、视线和演示计时器；每个角色有独立打招呼台词。

## 已实现互动

- 待机：轻微呼吸、眨眼。
- 指针在舞台移动：眼睛和头部小幅跟随；离开后回正；触屏不跟随。
- 点击角色或“打个招呼”：微笑与文字回应，2.4 秒后复原；支持键盘激活。
- 状态预览：待机、倾听、思考、说话。说话演示 5 秒后回到外部状态。
- 关闭口型：说话演示保持闭嘴。
- 尊重系统减少动态效果设置：停用循环动画和指针跟随。

## 状态与边界

`AvatarStage` 接受外部 `state`，预览期间临时覆盖，`stopDemo()` 恢复外部状态。
向父页面发送 `state-change`，确保状态按钮与实际舞台同步。
当前说话是固定节奏动作演示，无音频，不宣称音画同步。
真实对话、TTS 试听、时间轴及音量驱动尚未接入。

## 偏好

形象选择包含以上四个 ID，仅使用 2D，不提供 3D 模式选择。
当前页面登录后调用账户偏好接口；游客保存在本机，并按账户 ID / 游客隔离。
形象与声音、场景独立选择，语速 0.75–1.25 倍，可开关演示口型。

## 验收

页面可独立加载，无 3D 依赖；角色与缩略图一致；窄窗口无横向溢出；
点击回应与状态切换可见；关闭口型即时生效；保存后刷新恢复；
循环动画与定时器在组件卸载时停止。
