## 一、 核心商业与计费机制设计

### 1.1 「每日免费额度 + 超额积分抵扣（可开关）」双层漏斗模型

为了兼顾 **Free 免费用户留存体验** 与 **Pro / Enterprise 商业转化**，系统不采用一刀切阻断，而是对核心 AI 消耗型功能实行 **「三步走判定链路」**：

```text
用户发起 AI 请求（1v1 对话 / 1vN 多角色 / 听力划词 / AI 助教 / 复盘报告）
  │
  ├─ Step 1：检查功能等级门禁（Tier Gate）
  │    └─ 若属于高阶独占能力（如 ZIP 场景包导入/导出、私有知识库挂载）且等级不足 → 弹出【会员权益解锁弹窗】
  │
  ├─ Step 2：检查当日免费配额（Daily Free Quota）
  │    └─ 若 今日已用次数 < 当前等级每日免费额度 → 直接放行，记入今日免费使用次数（不扣积分）
  │
  └─ Step 3：超出免费额度 → 检查【超额使用积分抵扣开关（auto_use_credits）】
       ├─ 开关关闭（OFF）→ 拦截请求，提示「今日免费额度已用完，开启积分抵扣或升级 Pro 继续训练」
       └─ 开关开启（ON）
            ├─ 积分余额 ≥ 单次消耗积分 → 扣减对应积分，写入 CreditLedger 流水并放行（前端轻提示 `-2 积分`）
            └─ 积分余额 < 单次消耗积分 → 拦截请求，弹出【做任务领积分 / 升级订阅弹窗】
```

#### 「超额使用积分抵扣」双端开关设计
* **用户端自主开关（`User.auto_use_credits`）**：
  * 位于前端顶部算力胶囊下拉面板、练习室顶栏与会员中心，用户可随时切换 **「免费额度用尽后自动消耗积分」**（默认开启，也可设为每次弹窗确认或关闭以攒积分）。
* **管理端全局策略开关（`SaasConfig.allow_credit_overage`）**：
  * 管理员可在后台针对每一个功能项单独设置 **「是否允许 Free 用户超出免费额度后用积分抵扣」**（例如：允许 Free 用户用积分继续 1v1 对话和 1vN 多角色对话，但禁止 Free 用户用积分调用企业级 ZIP 导出）。

## 二、 积分获取生态：签到、日常任务、成就与活动体系

为了让 Free 用户能够通过持续学习“自给自足”体验高阶 AI 能力，同时提升全站日活（DAU）与完课率，构建四大积分获取渠道：

### 2.1 每日签到与连签激励（Daily Check-in）
* **基础签到**：每日首次点击签到获得 **+10 积分**（Pro 用户享有 **2 倍签到加成**，即 +20 积分）。
* **连续签到里程碑**：
  * 连续签到满 **3 天**：额外奖励 **+15 积分**
  * 连续签到满 **7 天**：额外奖励 **+40 积分** + 解锁「3 天 Pro 场景体验券」或高阶数字人试用
  * 连续签到满 **30 天**：额外奖励 **+150 积分**

### 2.2 每日训练任务（Daily Quests，每日 0 点刷新）
与 EchoTalk 现有业务模块深度联动，完成后自动触发（或点击领取）积分：

| 任务代码 | 任务名称 | 触发条件（关联现有业务表） | 奖励积分 | 每日上限 |
| :--- | :--- | :--- | :--- | :--- |
| `daily_practice_1` | 开口破冰 | 完成 1 场不少于 5 轮的 1v1 语音对话（`PracticeSession`） | **+15 积分** | 1 次 |
| `daily_listening_1` | 磨耳朵训练 | 在听力工作室完成 1 个单元精听或听写提交（`ListeningAttempt`） | **+10 积分** | 2 次 |
| `daily_review_10` | 记忆加固 | 在 SM-2 复习计划中完成 10 张卡片复习（`ReviewCard`） | **+10 积分** | 1 次 |
| `daily_debate_1` | 思维交锋 | 参与并完成 1 场多角色辩论或群面圆桌（`DebateSession`） | **+20 积分** | 1 次 |

### 2.3 新手成长任务（Onboarding Milestones，一次性）
* **注册破冰礼**：新用户注册即赠 **+100 积分**。
* **首次定制数字人**：在 [AvatarSettings.vue](file:///Users/mac/Files/EchoTalk/frontend/src/views/AvatarSettings.vue) 保存个人偏好的数字人形象与音色（**+20 积分**）。
* **首次自建场景**：在 [SceneEditor.vue](file:///Users/mac/Files/EchoTalk/frontend/src/views/SceneEditor.vue) 创建首个自定义 1v1 场景（**+30 积分**）。
* **首次达到 B2/85 分**：任意单场训练综合评分达到 85 分以上（**+50 积分**）。

### 2.4 运营活动与兑换码（Campaigns & Redeem Codes）
* **限时双倍积分活动**：管理端可配置活动时间段（如「周末口语冲刺日」「四六级备考周」），活动期间所有任务积分翻倍，或特定分类场景（如 CET 四六级、求职面试）免扣积分。
* **激活码 / 兑换码（Redeem Code）**：管理员可在后台批量生成兑换码（支持「纯积分礼包码」如 `ECHO-2026-888` 赠 200 积分，或「会员体验码」如 `ECHO-PRO-7DAYS` 赠 7 天 Pro 会员 + 500 积分）。

## 三、 三级订阅矩阵与「场景包/多角色包」权限拆分

针对 **场景包（`ScenePackage`）** 与 **多角色包（`Debate / Panel Package`）** 的创建、上传（导入 ZIP）、下载（导出 ZIP）和知识库挂载，按 C 端自用与 B 端教研/机构分发进行清晰隔离：

| 权益模块 | Free 免费版 | Pro 专业会员（¥29/月） | Enterprise 企业/机构版（¥199/月） |
| :--- | :--- | :--- | :--- |
| **开卡/月度赠送积分** | 注册送 100 积分（靠签到/任务获取） | **每月赠送 1,200 积分** + 签到双倍 | **每月赠送 10,000 积分** + 团队共享 |
| **超额积分抵扣特权** | 基础对话可用积分抵扣 | 全功能可用积分抵扣，且享 **8 折积分消耗** | 绝大部分功能无限免额 |
| **自定义场景数量上限** | 1v1 限 **2 个**，多角色限 **1 个** | 1v1 限 **30 个**，多角色限 **20 个** | **无数量限制** |
| **场景包 ZIP 上传（导入）** | ❌ 不支持（仅可使用官方场景） | ✅ **支持导入外部 `.zip` 场景包与多角色包** | ✅ **支持批量导入 `.zip` 场景包** |
| **场景包 ZIP 打包（导出）** | ❌ 不支持 | ❌ 不支持（防盗版二次分发） | ✅ **支持完整导出 `.zip`（含封面、人设、阶段、评分标准）用于教学/招聘分发** |
| **场景高阶配置能力** | 仅基础人设与开场白 | 解锁 **AI 草稿生成**、**自定义多阶段 (`stages`)**、**多角色圆桌 2~4 人编排** | 解锁 **自定义评分维度权重 (`evaluation`)**、**护栏词与关键词气泡 (`guardrails`)** |
| **私有知识库 (RAG) 挂载** | ❌ 不支持上传私有文档 | ✅ 支持上传最多 **15 份** PDF/MD/TXT（如个人简历、备考题库） | ✅ 支持上传 **200 份** 企业内训手册、产品白皮书并绑定场景 |
| **数字人形象与情感音色** | 官方基础形象 | 解锁全部高表现力 2D 数字人与多语速/情感音色 | 解锁全部 + 支持上传企业专属定制角色预设 |

## 四、 管理端（`admin/`）全项目模块补齐与升级规划

排查当前 [admin/src/router/index.js](file:///Users/mac/Files/EchoTalk/admin/src/router/index.js) 与 [admin.py](file:///Users/mac/Files/EchoTalk/backend/app/api/endpoints/admin.py)，现有管理端仅有 7 个基础页面，**缺失了 EchoTalk 2.0 近期新增的核心业务模块（多角色辩论/群面、知识库 RAG、SM-2 复习卡片）以及本次新增的 SaaS 运营模块**。

我们将管理端导航重构为 **三大分组、共 12 个标准模块页面**，实现对全站功能的 100% 覆盖与管控：

### 4.1 现有模块升级（对齐最新业务）

1. **`Dashboard.vue`（数据概览升级）**
   * **新增指标卡**：除现有的用户数、场景数、1v1 会话数外，新增 **「多角色交锋场次」「全站活跃 Pro/Enterprise 会员数」「今日积分发放 vs 消耗量」「知识库文档总数」**。
   * **新增趋势图**：近 7/30 天「1v1 vs 1vN 多角色 vs 听力训练」活跃度对比折线图、会员等级分布饼图。
2. **`Users.vue`（用户与会员权益管理）**
   * **新增列**：`会员等级 (Free/Pro/Enterprise)`、`到期时间`、`当前积分余额`、`今日免费额度使用率`、`超额扣积分开关状态`。
   * **新增操作抽屉/弹窗**：
     * **调整会员等级与有效期**（管理员一键为指定账号开通/延期 Pro 或 Enterprise）。
     * **积分手动调账**（增加/扣减用户积分，必填备注原因并写入 `CreditLedger`）。
     * **查看该用户专属积分账本与配额明细**。
3. **`Scenes.vue`（1v1 场景包管理升级）**
   * **新增字段与筛选**：增加 **`required_tier`（访问所需最低会员等级：`free` / `pro` / `enterprise`）** 设置，支持管理员在后台直接上传 `.zip` 场景包或导出任意场景为 `.zip`。
4. **`Sessions.vue`（全模式会话记录中心：1v1 + 1vN 合并分栏）**
   * **现状痛点**：目前仅展示 `PracticeSession`（1v1），无法查看 `DebateSession`（多角色辩论/群面）。
   * **升级方案**：顶部增加 Tab 切换 **`[1v1 语音对话记录]`** 与 **`[1vN 多角色交锋记录]`**，支持查看多角色会话的阶段推进、各 AI 角色发言、胜率/委员会认可度变化及赛后裁决报告。
5. **`TokenStats.vue`（API Token 与 SaaS 算力损益看板）**
   * **新增「积分 vs 真实 Token 核算面板」**：关联 `CreditLedger` 与 `ApiTokenUsage`，统计每消耗 1 个回声积分对应消耗的底层 LLM Token 均值，监控是否有异常刷量用户。

### 4.2 新增补齐的项目业务管理模块（填补管理端空白）

6. **新增 `DebateTopics.vue`（多角色场景管理：`debate` 辩论 + `panel` 群面圆桌）**
   * **路由**：`/debates`
   * **核心功能**：
     * 列表管理全站所有的多角色场景（`DebateTopic`），按子模式筛选（`debate` 正反辩论对抗 / `panel` 多人圆桌·群面委员会）、按来源筛选（官方内置 / 用户自建）、按难度与分类筛选。
     * 查看与编辑多角色配置详情：2~4 位 AI 角色阵容（`roles_config`：头衔、人设、绑定数字人、音色）、3~4 个议程阶段（`stages_config`）、允许工具开关（`tools_config`：知识检索、实时打分、事实核查、灵感提示）。
     * 设置场景的 **会员门禁等级（`required_tier`）**、公开/归档状态、**后台直接导入/导出多角色 `.zip` 包**。
7. **新增 `KnowledgeAdmin.vue`（知识库与 RAG 文档管理）**
   * **路由**：`/knowledge`
   * **核心功能**：
     * 统一管理全站 `Document` 与 `DocumentChunk`（包含官方场景内置资料与用户上传的私有文档）。
     * 展示文档名称、所属用户、绑定场景（1v1 或 1vN）、文件大小、分块数量（`chunk_count`）、向量化状态（`indexed` / `failed`）。
     * 支持管理员预览文档切片内容、强制重建向量索引、清理失效或违规文档、查看用户知识库配额占用情况。
8. **新增 `ReviewsAdmin.vue`（复习计划与学习记录管理）**
   * **路由**：`/reviews`
   * **核心功能**：
     * 汇总查看全站用户的 SM-2 复习卡片（`ReviewCard`）与听力闯关提交记录（`ListeningAttempt`）。
     * 统计高频易错词汇/句型排行榜、各记忆阶段（新卡 / 学习中 / 已掌握）分布，支持管理员批量清理测试数据或将优质纠错表达沉淀为官方推荐复习卡。

### 4.3 新增 SaaS 商业化运营模块

9. **新增 `SaasPlans.vue`（SaaS 套餐与功能配额配置中心）**
   * **路由**：`/saas/plans`
   * **核心功能**：
     * **套餐卡片配置**：可视化编辑 `Free`、`Pro`、`Enterprise` 三档套餐的展示名称、模拟月付/年付价格、每月赠送积分、最大可建 1v1 场景数、最大可建多角色场景数、最大知识库文档数、ZIP 导入/导出权限开关。

10. **新增 `TasksAndCampaigns.vue`（积分任务、签到与活动管理）**
    * **路由**：`/saas/tasks`
    * **核心功能**：
      * **签到规则配置**：修改每日基础签到积分、连续 3/7/30 天额外奖励积分、Pro 会员倍率。
      * **日常/新手任务列表管理**：启用或停用各项积分任务（如开口破冰、磨耳朵、记忆加固），动态调整任务目标次数与奖励积分数。
      * **限时运营活动管理**：创建「周末积分翻倍」「面试季限免」等活动（配置起止时间、加成倍率或限免功能列表）。
11. **新增 `OrdersAndCodes.vue`（模拟订单、积分账本与兑换码中心）**
    * **路由**：`/saas/orders`
    * **核心功能**：
      * **模拟订阅/充值订单列表**：展示用户在前端通过「模拟收银台」发起的套餐升级与积分加油包订单。
      * **全站积分变动流水账本（`CreditLedger`）**：按用户、变动类型（签到/任务奖励/对话消耗/后台调账/兑换码）检索每一笔积分收支明细。

## 六、 后端 API 与服务层设计

### 6.1 核心配额与积分守卫服务（`backend/app/services/saas_service.py`）

提供统一的 `check_and_consume_quota(db, user, action_key, ref_id=None)` 函数，在以下关键节点调用：

1. **1v1 语音对话轮次提交**（`app/api/endpoints/sessions.py` -> `submit_turn` / `stream_turn`）：
   * 调用 `check_and_consume_quota(db, user, "practice_turn", ref_id=session_id)`。
   * 轮次完成后自动调用 `trigger_task_progress(db, user.id, "daily_practice_1")` 更新日常任务进度。
2. **1vN 多角色对话轮次提交**（`app/api/endpoints/debate.py` -> `submit_debate_turn`）：
   * 调用 `check_and_consume_quota(db, user, "debate_turn", ref_id=session_id)`。
   * 会话结束生成裁决书时调用 `trigger_task_progress(db, user.id, "daily_debate_1")`。
3. **听力划词解释与 AI 助教**（`app/api/endpoints/listening.py`）：
   * 调用 `check_and_consume_quota(db, user, "listening_explain")`。
4. **场景包 / 多角色包 ZIP 导入与导出**（`app/api/endpoints/scenes.py` & `debate.py`）：
   * 导入 ZIP 校验 `plan_config.allow_zip_import == 1`（Pro 及以上开放）。
   * 导出 ZIP 校验 `plan_config.allow_zip_export == 1`（Enterprise 开放）。
