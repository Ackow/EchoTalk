# EchoTalk 2.0 产品官网与文档站 (`docs/`) 开发文档

> **文档定位**：本文档说明位于 `docs/` 目录下的 EchoTalk 2.0 产品官网（5 个独立页面）的架构设计、触感紫白视觉规范、静态资源管理与本地开发构建流程。

---

## 一、 技术栈与多页面路由架构

官网基于 **Vue 3 + Vue Router 4 + Vite 5** 构建，拆分为 **5 个独立路由页面**，与主客户端保持一致的**触感紫白（Tactile Lavender & White）**设计系统：

| 导航项 | 路由路径 | 对应视图文件 | 核心模块与交互 |
| :--- | :--- | :--- | :--- |
| **产品介绍** | `/` | `docs/src/views/Home.vue` | Hero 主视觉 + 带 macOS 窗口框的交互式多 Tab 预览舱（真实桌面截图 + 群面委员会动态声波模拟 + 主页插画）+ 悬浮呼吸徽章 + Zig-Zag 交替介绍 |
| **核心特性** | `/features` | `docs/src/views/Features.vue` | 1v1、1vN、听力四六级、Hybrid + LightRAG、SM-2 复习、2D 数字人六大能力卡片 + 8 张官方高清场景封面画廊 |
| **订阅方案** | `/pricing` | `docs/src/views/Pricing.vue` | 按月/按年（红色删除线对比）切换、Free/Pro/Enterprise 三档卡片、回声积分加油包、5 大维度对比表与计费 FAQ 手风琴 |
| **场景社区** | `/community` | `docs/src/views/Community.vue` | 触感紫白场景包市场，支持按 1v1 / 1vN / 面试 / 日常筛选与 `packages.json` 清单下载 |
| **产品文档** | `/docs` | `docs/src/views/Docs.vue` | 紫白侧边目录树 + 深色高对比度代码块 + 2.0 双轨架构、ScenePackage v2、LightRAG 与 SaaS 运维指南 |

---

## 二、 目录结构与静态资源

```text
docs/
├── index.html
├── package.json
├── vite.config.js
├── public/
│   ├── images/
│   │   ├── brand.png                 # EchoTalk 品牌 Logo
│   │   ├── hero-cartoon.png          # 主页插画
│   │   ├── practice-desktop.png      # 1v1 语音对话工作台真实截图
│   │   └── covers/*.png              # 8 张官方 1v1 & 1vN 场景高清封面
│   ├── packages.json                 # 社区场景包构建清单
│   └── scenes/*.zip                  # 可下载场景包归档
└── src/
    ├── router/index.js               # 5 独立页面路由配置
    ├── styles/global.css             # 触感紫白全局设计令牌
    ├── components/
    │   ├── Navbar.vue                # 毛玻璃顶栏导航
    │   ├── AppFooter.vue             # 页脚
    │   └── EchoCreditIcon.vue        # 回声积分专属星币矢量图标
    └── views/                        # Home / Features / Pricing / Community / Docs
```

## 三、 本地开发与构建

```bash
cd docs

# 首次安装依赖
npm install

# 启动本地开发预览服务器
npm run dev

# 生成场景清单并打包生产产物（输出至 docs/dist/）
npm run build
```
